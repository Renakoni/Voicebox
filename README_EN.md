## What it does

- **Truly on-device**: once the models are downloaded, generation runs entirely on the phone. The GPU path uses WebGPU, Qualcomm devices can add hybrid NPU acceleration, and the app falls back to CPU when no GPU is available.
- **Bring your own weights**: pick the `.ckpt` and `.pth` files GPT-SoVITS produced and Voicebox converts them on the phone. V2 Pro, V2 Pro Plus and V5 Turbo are supported, with no desktop export step.
- **Send as a QQ voice message**: tap "去 QQ 发送" after generating, pick a contact, and the recipient gets a native voice message they can tap to play, not an audio file. [Watch the QQ sending demo (14 s)](https://github.com/Renakoni/Voicebox/blob/main/.github/assets/demo-qq.mp4)
- **Local HTTP service**: enable the local API in settings so Tasker, audiobook apps and other clients on your phone can request speech generation. Desktop clients can connect through ADB port forwarding.

Output language and reference language are set separately, so a voice cloned from a Japanese clip can still speak Chinese and English.

## Getting started

Download **Voicebox 1.1.2** (72.6 MiB) from [Releases](https://github.com/Renakoni/Voicebox/releases/latest). It needs an **ARM64 device running Android 11 or later**, and installs directly over earlier official releases.

1. **Get a model**: on the 音色 (Voices) tab, download the official V2 Pro Plus or V5 Turbo, and the app prepares the shared resources with it. Or tap 导入音色 (Import) and pick your own `.ckpt` and `.pth`.
2. **Clone a voice**: choose a base model, hold to record or pick a reference clip, enter its transcript and language, and save.
3. **Generate**: back on 创作 (Create), choose the voice and output language, type your text and tap 生成语音. Then play, save, share, or send it to QQ.

<details>
<summary><strong>One-time setup for QQ voice messages</strong></summary>

1. Turn on Wireless debugging in the system Developer options.
2. On Voicebox's 发送 QQ 语音 page, tap 连接 and enter the six-digit pairing code the system shows. You only pair once.
3. Tap 选择联系人并发送 and open the target chat in QQ. Voicebox records a placeholder, swaps in your audio and sends it. Don't touch QQ while it works.

Each message must be shorter than 60 seconds.

## How fast is it?

> **TL;DR**: on a Xiaomi 14 (Snapdragon 8 Gen 3), V2 Pro Plus turns a 4-second sentence around in about **2.6 s**, and long passages run at an RTF of about **0.51**, roughly twice as fast as playback. V5 Turbo with the NPU reaches an RTF of **0.95** on long passages, also faster than playback. All offline.

Short clips are about **4 s** of audio and long passages about **22 s**, using official weights and the same Chinese reference clip. After models and caches are loaded, each configuration and length is generated **10 times**; values are **mean ± standard deviation**.

The GPT-SoVITS rows use the models and code from the [official repository](https://github.com/RVC-Boss/GPT-SoVITS) on a laptop with an **i9-12900H, RTX 3070 Ti Laptop (8 GB VRAM) and 16 GB RAM**. All Voicebox rows were measured on a **Xiaomi 14 (Snapdragon 8 Gen 3, 16 GB RAM)**.

| Model | Implementation / device | Short time (s) | Short RTF | Long time (s) | Long RTF |
|---|---|---:|---:|---:|---:|
| V2 Pro Plus | GPT-SoVITS · i9-12900H | 7.008 ± 0.950 | 1.752 ± 0.249 | 39.173 ± 1.097 | 1.731 ± 0.030 |
| V2 Pro Plus | GPT-SoVITS · RTX 3070 Ti Laptop | 1.380 ± 0.382 | 0.341 ± 0.089 | 6.153 ± 0.301 | 0.265 ± 0.007 |
| V2 Pro Plus | Voicebox · GPU | 2.587 ± 0.182 | 0.614 ± 0.043 | 12.637 ± 0.453 | 0.556 ± 0.005 |
| V2 Pro Plus | Voicebox · GPU + NPU | 2.618 ± 0.927 | 0.627 ± 0.286 | 11.955 ± 0.608 | 0.511 ± 0.007 |
| V5 Turbo | GPT-SoVITS · i9-12900H | 12.660 ± 0.859 | 3.162 ± 0.209 | 71.061 ± 3.277 | 3.137 ± 0.049 |
| V5 Turbo | GPT-SoVITS · RTX 3070 Ti Laptop | 1.680 ± 0.326 | 0.416 ± 0.086 | 6.217 ± 0.566 | 0.278 ± 0.021 |
| V5 Turbo | Voicebox · GPU | 8.173 ± 0.429 | 2.038 ± 0.102 | 40.676 ± 2.589 | 1.816 ± 0.043 |
| V5 Turbo | Voicebox · GPU + NPU | 5.367 ± 0.301 | 1.313 ± 0.074 | 21.479 ± 0.867 | 0.954 ± 0.021 |

**RTF = generation time ÷ audio duration**. Lower is faster, and below 1 means generation outpaces playback. The phone GPU path is CPU + WebGPU; the NPU path is Qualcomm QNN hybrid acceleration. NPU is optional and experimental: the APK does not ship the QNN runtime, so it is used only on devices that already have a compatible runtime and pass validation. Everything else runs on the GPU.

## How close is it to the original?

> **TL;DR**: given identical inputs and noise, the phone's V2 Pro Plus output differs from official PyTorch FP32 by about **0.23%** RMS. Running speech recognition over 160 clips, phone-generated audio transcribes back at over **99%** accuracy, on par with the official desktop implementation.

Waveform error compares the full acoustic output of GPU + NPU against official PyTorch FP32 with fixed inputs and noise, one short and one long case. Transcription accuracy uses SenseVoice on the 160 clips above, 10 short and 10 long per configuration.

| Model | RMS short | RMS long | ASR · official CPU | ASR · official CUDA | ASR · phone GPU | ASR · phone GPU + NPU |
|---|---:|---:|---:|---:|---:|---:|
| V2 Pro Plus | 0.2323% | 0.2351% | 98.87% | 99.06% | 99.34% | 99.72% |
| V5 Turbo | 1.4489% | 0.6537% | 99.53% | 99.25% | 99.72% | 99.62% |

- **Relative RMS error** = `RMS(phone − official) ÷ RMS(official) × 100%`. Lower means closer.
- **ASR transcription accuracy** = `(1 − character edit distance ÷ reference length) × 100%`, punctuation removed. Higher means closer to the input text.

## Building from source

Requires JDK 21, Android SDK 37 (with NDK and CMake) and Python 3.12+.

```powershell
git clone https://github.com/Renakoni/Voicebox.git
cd Voicebox
python -m pip install numpy onnx
python tools/prepare_language_assets.py
cd Android
.\gradlew.bat :app:assembleDebug
```

The default build runs inference on CPU. WebGPU acceleration needs a custom ONNX Runtime ([build script](tools/build_ort_webgpu.ps1), [patches](patches)), passed in with `-PgenieOrtAar=<path-to-AAR>`.

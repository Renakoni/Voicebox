# 实现方案与优化

一次语音克隆从两段文本与一段参考音频开始：一段是录音对应的原台词，另一段是待合成的目标文本。系统先从录音与原台词中提取参考声学特征，再结合目标文本通过语义模型预测自回归语义编码序列；声学模型接续这串编码，最终合成可播放的时域波形。

Voicebox 沿用 GPT-SoVITS 架构并结合 Genie-TTS 在 Android 端侧的落地工程。在移动设备算力与内存受限的环境下，除了模型本身的计算负载，张量在内存中的读写以及异构处理器间的数据搬运也是决定实时率的关键因素。

## 从参考录音到语义编码

在连续合成相同音色的句子时，参考音频、原台词及提取出的说话人特征保持不变。系统在内存中保留这部分预处理结果，后续句子直接复用；仅在修改原台词或更换录音时，才重新计算对应的参考特征。

语义模型在自回归生成时，每步预测都需要回看完整的历史注意力状态。由于历史编码的键与值在后续步骤中保持不变，系统通过 KV Cache 直接复用历史状态。为了避免追加编码时频繁触发内存重新分配与整段数据搬运，解码器采用预分配缓冲区的策略，在末尾原地写入新状态，仅在初始容量耗尽时才执行阶梯扩容。

自回归解码每步仅生成一个编码，模型权重读取属于典型的带宽受限操作。我们将模型权重以 FP16 格式存储，将访存数据量降低一半；计算时再根据精度需求转回 FP32 执行乘加运算，在维持数值精度的同时显著降低显存带宽压力。

在序列预测的采样环节，系统沿用 GPT-SoVITS 的指数抽样方案：为各候选编码分配独立指数分布随机数并除以预测概率，以最小等待时间决出结果。该方法在数学上严格符合模型输出的概率分布，同时省去了全局概率归一化与排序开销，单次遍历即可在线确定采样结果并追加至历史序列。

## V2 Pro Plus

### 声学特征展开与异构划分

语义序列就绪后，声学模型将其与目标文本及说话人条件融合，生成沿时间轴排列的声学特征序列。声码器随后执行逐级时域上采样，按每帧 640 个采样点的倍率生成 32kHz 波形。

前级特征准备逻辑包含可变长度处理与掩码计算，算子分支较多，统一交由 CPU 在 FP32 精度下调度。声码器阶段虽然计算密集，但张量在时域上迅速膨胀。若过早交接，CPU 与 GPU 之间需要搬运庞大的展开数据。因此系统将硬件交接点严格设置在声码器入口：CPU 完成紧凑特征的准备后单次提交给 GPU，GPU 集中并发执行后续的多级卷积上采样，彻底规避展开后大张量的跨设备传输开销。

### 转置卷积的多相分解

声码器常使用转置卷积实现时域上采样。传统实现依赖插零操作，存在大量与零相乘的无效计算。我们基于多相分解思想，将卷积核权重按输出相位拆分为独立的子权重组：GPU 直接在原始未填充的输入序列上并发执行各组子卷积，随后按时序交错拼接输出。该优化在保持计算等价的同时完全跳过了乘零计算，使上采样阶段的卷积效率成倍提升。

### 长音频分窗与 NPU 加速

声码器中的卷积计算受限于局部感受野，单个波形采样点仅依赖有限时域范围内的前序与后序特征。据此，长音频可以沿时间轴切分为等长窗口，复用固定尺寸的模型进行推理。

为保证窗口接缝处的波形连续性，系统采用 64 帧为基准窗口，并在两侧各保留 8 帧重叠区域作为上下文感受野。拼接波形时，每个窗口仅截取感受野完整的中心区域，边缘部分则由相邻窗口提供，彻底消除了分块缝隙带来的杂音与相位断层。

执行流程上，CPU 先行将全局说话人条件融合至完整特征中；密集的中间卷积层切窗后交由 NPU 以 FP16 执行；最后的波形输出投影层再回传至 CPU 以 FP32 计算，避免数值精度截断对音频底噪产生影响。对于本身耗时较短的短句，固定窗口切分与设备间切换的开销占比偏高，系统自动退回至 GPU 一次性计算完成；仅当序列长度超过阈值、足以摊薄调度成本时，才启用 NPU 分窗并行管线。

## 两种声学模型的分工

V2 Pro Plus 的声码器具有纯局部时域依赖，因而可以基于卷积感受野直接切分滑动窗口；而 V5 Turbo 在波形合成前需要先通过扩散模型生成梅尔频谱，其内部的自注意力机制涵盖了全局时序关联，若强行缩小窗口会破坏注意力视野。因此 V5 Turbo 保留了频谱生成阶段原有的分块粒度，通过阶段解耦与异构流水线进行加速。

## V5 Turbo

### 频谱分块与时序条件衔接

V5 Turbo 接收语义编码后，先通过 DiT 扩散模型预测按时序排列的梅尔频谱，再由声码器转化为 48kHz 波形。随着序列增长，自注意力机制的计算开销呈平方级上升，长音频必须沿时序划分成多个分块依次求解。

首个分块以录音参考音频作为先验条件。处理后续分块时，系统提取前序分块末尾生成的梅尔频谱，替换参考条件末尾的对应切片。这样既保留了原始音频全局的说话人音色，又为当前分块提供了前序音频自然的语调走势与声学衔接上下文。确定分块的输入后，模型一次性完成条件嵌入与时序位置编码的构建。

端侧 NPU 推理通常要求固定的输入形状。如果为每个实际长度单独编译模型，会面临漫长的即时编译延迟；若直接填充至全局最大长度，短分块又会浪费大量无效计算。系统采用分档编译策略，预设若干离散长度档位，推理时匹配大于等于当前长度的最小档位，多余部分通过注意力掩码屏蔽。各档位按需加载并缓存编译产物，编译完成后立即释放原始权重会话，避免在内存中常驻多份冗余模型副本。

### 4 步扩散推理的混合精度协同

每块梅尔频谱从初始高斯噪声开始去噪，DiT 固定以 4 轮步长完成数值求解。各轮次中，语义条件与帧位置编码完全固定；时间步嵌入也仅有 4 个离散取值，可以在分块初始阶段一次性计算完成供各轮复用。

DiT 包含密集的自注意力与前馈网络，同层内的张量计算可在整个分块上高度并行。系统采用异构混合精度方案：
- 前三轮去噪计算量最大，交由擅长 FP16 矩阵乘法的 NPU 连续执行，中间激活值完全保留在片上。
- 模型各层采用的 GELU 激活函数原生依赖双曲正切计算，在 NPU 上开销较高；我们将其替换为计算代价更低的 Sigmoid 快速近似形式，利用硬件内置的高效向量指令显著加速，且听感评测无损。
- 第四轮去噪作为直接输出给声码器的终态修正，对数值精度敏感，系统将其调度至 GPU 以 FP32 执行，避免低精度截断在最终频谱中引入杂音底噪。

### 双引擎重叠流水线与无缝波形拼接

分块生成机制天然支持异构硬件的流水线并行：当 NPU 正在计算当前分块的前三轮频谱时，GPU 可以并发承接前一分块的第四轮去噪以及声码器波形合成，使移动端算力保持全负荷运转。

声码器卷积在边界处同样需要依赖相邻时段的频谱上下文。当前分块合成时，系统首先提取感受野完备的中心段波形，将边缘区域推迟至下一分块首部频谱计算完成后合并卷积。各分块输出的时域波形按时序无缝拼接，最终合成自然连贯的完整音频。
